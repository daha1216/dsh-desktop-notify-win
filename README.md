# DSH 桌面通知（Windows）

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 用的 Windows 桌面通知插件：**会话完成、需要你回答、需要授权（含权限提升）、agent 出错**时，在鼠标所在显示器的角落弹一张卡片。点一下卡片就切回 DSH 所在的虚拟桌面并聚焦。

- 适用于 Windows 10/11 上的 DSH 桌面版 / Web GUI
- 纯本地运行，不联网、不收集数据
- 无第三方运行时依赖

## 功能

| 时机 | 卡片标题 |
|---|---|
| 本轮完成 | DSH · 本轮完成 |
| agent 出错 | DSH · 出错了 |
| 需要你回答问题 | DSH · 需要你回答 |
| 需要授权 / 权限提升 | DSH · 需要你确认 |

- **授权、提权不漏**：沙箱权限提升、工具授权、插件管理提权都会通知；插件自己在更新时，安装那一步的提权也会通知。
- **跟随鼠标显示器**：卡片出现在鼠标所在屏幕的角落，不是固定主屏。
- **带会话标题**：正文第一行显示当前会话标题。
- **点击即回**：一步切到 DSH 所在虚拟桌面并聚焦；最大化和普通窗口保持原尺寸，只有最小化时才恢复。「DSH 原生」版式下点右上角 × 只关卡片、不切回。
- **不抢焦点**：卡片置顶但不激活，不打断正在输入的内容。
- **可调外观**：8 套预设 + 实时预览 + 三套版式（条状 / 卡片 / DSH 原生）+ 颜色、圆角、色条、内边距、字号字体、投影高光、底部进度条、宽度、整体缩放、透明度、时长、声音、位置、边距。
- **保存立即生效**：不用重启 DSH。
- **测试通知**：用页面上的当前值预览，不必先保存。

## 安装

### 方式一：DSH 里添加（推荐）

1. 打开 DSH 设置 → **插件** → **添加插件**。
2. 粘贴仓库地址：

   ```
   https://github.com/daha1216/dsh-desktop-notify-win
   ```

3. 点安装，装完刷新一次页面。
4. 打开 设置 → **桌面通知** 调整样式。

> 「添加插件」支持包名、GitHub 仓库地址、本地目录。这个插件目前通过 GitHub 安装，仓库需要是公开的。

### 方式二：命令行

```powershell
dsh plugin --profile desktop add https://github.com/daha1216/dsh-desktop-notify-win
```

把 `desktop` 换成你的 profile 名。

### 方式三：本地目录

在「添加插件」里填本目录的绝对路径，例如：

```
D:\AI\dsh-desktop-notify
```

### npm（可选，发布后可用）

```powershell
dsh plugin --profile desktop add dsh-desktop-notify-win
```

> 包名特意用了 `-win` 后缀，避免和 npm 上已有的同名项目混淆。

## 使用

- 正常用 DSH；触发时卡片自动出现。
- 鼠标移上去暂停倒计时，移开继续；点卡片切回 DSH。
- 设置页顶部有「保存 / 测试通知」；改完可以直接点测试看效果，满意再保存。

## 设置说明

- **快速样式**：经典深色、系统浅色、极简灰、高对比、霜白圆角、午夜霓虹、卡片版式、DSH 原生。每套都完整记录了形状与质感参数，选中后仍可继续微调。
- **布局**：三套版式。条状（默认，一行标题加正文）、卡片（图标 + 小标题 + 大标题 + 多行正文 + 状态行，按 12 栏网格排版，图标占前两栏，文字从第三栏起；色条与进度条自动隐藏，卡高随正文行数自适应）、DSH 原生（复刻 DSH Web 自己的白底大卡：51×51 圆角图标板里的鲸鱼、Segoe UI Semibold 应用名、约 24px 标题、18px 正文 31px 行距、底部红点状态行（`status` 留空时显示倒计时，悬停变「已暂停」）+ 「点击切回 ›」、右上角关闭 ×；同样隐藏色条与进度条，整体缩放（50%–150%）连同字号、图标、间距一起等比缩放）。
- **实时预览**：按当前表单渲染，含圆角、色条、投影、进度条、位置、宽度、缩放、透明度。
- **外观**：左侧色条、卡片底色、文字颜色、宽度、整体缩放、透明度。
- **形状与排版**：圆角、色条宽度、水平/垂直内边距、标题字号、正文字号、字体。
- **质感**：投影强度、顶部高光、底部进度条、标题圆点、淡入淡出。
- **弹出与停留**：显示多久、弹出角、离屏幕边缘、提示音。
- 保存后立即生效，不用重启 DSH。卡片按显示器 DPI × 整体缩放绘制，高分屏下不再发虚。

## 本地改造记录

这一份是定制版（基于上游 [0.4.0](https://github.com/xiaotie3088/dsh-desktop-notify-win)）：

- 卡片不再用 WinForms 控件堆叠，改为分层窗口 + UpdateLayeredWindow 手绘：圆角、同心层投影、左侧渐变强调条、标题圆点、贴底进度条、顶部高光、淡入淡出，高度随正文行数自适应（最多 3 行）。
- 渲染进程调用 SetProcessDPIAware，200% 缩放下按真实像素绘制。
- 新增 13 个配置字段：`radius` `padX` `padY` `accentWidth` `titleSize` `bodySize` `progress` `icon` `fade` `shadow` `shine` `font` `scale`，宿主 `sanitize()` 一并放宽校验。
- 设置页预设由 4 套扩到 8 套，新增 Slider / Switch 控件与高保真预览。
- 版面改由 `layout` 字段切换（`bar` / `card` / `dsh`）：卡片版式移植自 CPAMC 启动卡，12 栏网格、图标块占两栏、文字占三到十二栏，配 `status`（状态行文案）与 `eyebrow`（标题上方的小字）。卡片模式下色条与进度条自动停用，渲染时按相位给状态点画扩散环。
- 第三套版式 `dsh` 按 DSH Web 自带错误卡逐像素复刻（参考 `dsh-error-card.html` / `dsh-error-card-compare.png`）：51×51 图标板 + 手绘鲸鱼轮廓、`Segoe UI Semibold` 应用名、字号按 `titleSize`/`bodySize` 以固定倍率派生（1.60 / 1.385）、正文行距 1.69、footer 红点 + 「点击切回 ›」、右上 × 独立热区（点 × 只关卡片）。配色不写死，全部由底色与文字色按比例混合、浅色底再补一点冷色派生；投影改为 7 层更弱的堆叠，描边用两层差分环拼出「上左 2px、下右 1px」的原生观感。`eyebrow` 在该版式下是应用名（默认 DeepSeek Harness），`status` 是红点后面那行小字，留空时显示「N 秒后收起 · 悬停可保留」、鼠标悬停变「已暂停 · 移开继续」（BUILD 18 起），填了则显示自定义文案。
- `notify.ps1` 新增 `-Snapshot <path>` 参数：不弹窗，直接把静态帧写成 PNG，方便调样式。
- BUILD 19 新增 `scale`（50%–150%，默认 100%）：渲染入口把屏幕 DPI 缩放系数乘以它，之后所有尺寸、字号、间距、圆角、阴影都按同一个系数绘制，三套版式都是整张卡片等比缩放。设置页「颜色与大小」里「卡片宽度」下面是 5% 步进的「整体缩放」滑杆，实时预览同步缩放（放大超过 100% 时预览只画到原始尺寸，避免被预览框裁切）。

## 资源占用

- 空闲时：DSH 进程里的一小段 JS，无常驻进程、无轮询、无网络请求。
- 每次弹窗：一个短命的 `powershell.exe`，实测约 97MB 内存、约 2 秒 CPU，卡片消失后进程退出。
- 设置页：只在打开时渲染。

## 常见问题

**装完设置里没有「桌面通知」？**
刷新一次 DSH 页面；客户端模块需要重新加载。插件更新后也一样。

**测试有卡片，但真实通知样式没变？**
「测试通知」用页面上的当前值；真实通知用已保存的值。改完点「保存」。

**没有任何卡片？**
先看插件目录下的 `notify-debug.log` 和 `notify-click.log`（日志不会上传，也不会随插件发布）。常见原因：专注助手/勿扰模式、全屏独占游戏、系统通知被关闭。

**提权时没有卡片？**
插件监听会话审计事件 `approval/asked`，正常应覆盖权限提升与工具授权；会话权限策略为 `never` 时不会出现确认提示，也就没有卡片。

**更新插件时连续两次提权？**
一次更新包含 `remove_bundle` + `install_bundle` 两步，两次都会弹卡片。

## 已知限制

- 仅 Windows（依赖 WinForms / PowerShell）。
- 虚拟桌面切换用的是未公开 COM，Windows 大版本更新后可能失效；失效时退化为只聚焦。
- 多显示器跟随已按代码和单屏日志验证，真·双屏还需实机测试。
- 专注助手/全屏独占可能吞掉卡片，这是系统行为。

## 隐私

插件完全本地运行，不发送任何网络请求。`notify-debug.log` / `notify-click.log` 只写在插件目录，可能包含窗口标题等本机信息；它们已在 `.gitignore` 中，不会进入仓库或 npm 包。
