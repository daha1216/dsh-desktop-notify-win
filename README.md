# DSH 桌面通知（Windows）

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 用的 Windows 桌面通知插件：**本轮完成、需要你回答、需要授权、agent 出错、插件就绪**时，在屏幕角落弹一张卡片。点一下卡片就切回 DSH 所在的虚拟桌面并聚焦。

这一份是 [xiaotie3088/dsh-desktop-notify-win](https://github.com/xiaotie3088/dsh-desktop-notify-win) 的定制版（BUILD 20，版本 0.5.0），在原版基础上重做了设置页、渲染宿主与通知调度，详见文末「本地改造记录」。

- 适用于 Windows 10/11 上的 DSH 桌面版 / Web GUI
- 纯本地运行，不联网、不收集数据
- 无第三方运行时依赖

## 功能

| 时机 | 事件 | 默认 |
|---|---|---|
| 本轮完成（agent 空闲） | `turnEnd` | 开 |
| Agent 在等你回答问题 | `question` | 开 |
| 有工具调用等你授权 / 权限提升 | `approval` | 开 |
| Agent 执行出错 | `error` | 开 |
| 插件启动就绪 | `startup` | 关 |

- **五类事件都能单独开关**。关掉的事件不弹窗，但仍会写入「最近通知」，并注明「事件已关闭」。
- **免打扰时段**：可以设一个起止时间（支持跨午夜），期间只记历史不弹窗。
- **不打扰正在干活的你**：DSH 在前台、全屏应用 / 系统勿扰（Windows 通知状态 2/3/4/7）、专注助手（状态 6）都可以分别抑制。被抑制的通知会保留在历史里，写明原因。
- **最多同屏几张**：1–5 张，超出的直接关掉最早一张（不是排队）。
- **显示器可选**：跟随鼠标所在屏，或固定主屏。
- **点击行为可选**：点了切回 DSH（会切虚拟桌面并聚焦，尽量不改变窗口大小），或只关卡片。DSH 版式下点右上角 × 永远只关卡片。
- **三种版式 + 八套预设**：横条、卡片、DSH 白卡。预设只是起点，所有参数都能继续微调。
- **设置页即时预览**：右侧按当前表单值实时渲染，保存后立即生效，不用重启 DSH。
- **测试通知**：不保存也能先看效果。
- **最近通知**：保留最近 50 条（页面显示 30 条），可以重播任意一条，也能看到被抑制的原因。
- **导入 / 导出**：设置可导出为 JSON 备份，导入时只接受已知字段。

## 安装

### 方式一：DSH 里添加（推荐）

1. 打开 DSH 设置 → **插件** → **添加插件**。
2. 粘贴仓库地址：

   ```
   https://github.com/daha1216/dsh-desktop-notify-win
   ```

3. 点安装，装完刷新一次页面。
4. 打开 设置 → **桌面通知** 调整样式。

> 「添加插件」支持包名、GitHub 仓库地址、本地目录。仓库需要是公开的。

### 方式二：命令行

```powershell
dsh plugin --profile desktop add https://github.com/daha1216/dsh-desktop-notify-win
```

把 `desktop` 换成你的 profile 名。

### 方式三：本地目录

在「添加插件」里填本目录的绝对路径，例如：

```
D:\AI\dsh-desktop-notify-win
```

### npm（可选，尚未发布）

```powershell
dsh plugin --profile desktop add dsh-desktop-notify-win
```

> 包名带 `-win` 后缀，避免和 npm 上已有的同名项目混淆。

## 使用

- 正常用 DSH；触发时卡片自动出现。
- 鼠标移上去暂停倒计时，移开继续；点卡片按「点击行为」处理。
- 设置页顶部有「测试通知 / 保存」；没保存时标题旁会显示「未保存」，刷新或关页面会提示。
- 「最近通知」里每条都带事件类型、时间、显示状态；点「重播」会用它当时的文案再弹一次；重播是强制显示，不受事件开关、免打扰和前台 / 全屏抑制影响。

## 设置页说明

设置页分六段：

1. **通知什么**：五个事件开关。
2. **什么时候不打扰**：免打扰时段、DSH 前台、全屏 / 勿扰、专注助手、最多同屏、显示器、点击行为。
3. **样式**：三套版式、八套预设、停留时长（3–120 秒，带 5/8/20/60 快捷键）、提示音、整体缩放（50%–150%）；展开「外观细节」后可以调颜色、宽度、圆角、色条宽度、内边距、字号、字体、状态行、应用名、投影、高光、进度条、图标、淡入淡出、减少动效、高对比、语义色。
4. **最近通知**：刷新、清空（两次确认）、重播、查看抑制原因。
5. **数据与维护**：数据目录、配置来源、导出 / 导入 / 恢复默认。
6. **实时预览**：右侧固定，随表单变化；下面有当前摘要和「用当前值测试」。

### 外观细节里的几个约定

- **版式**：横条（一行标题 + 正文 + 进度条）、卡片（12 栏网格，图标板 + 小标题 + 大标题 + 正文 + 状态行）、DSH 白卡（复刻 DSH Web 自己的白底大卡：图标板里的鲸鱼、应用名、标题、正文、彩色状态点 + 状态文案、右上角 ×）。
- **状态行文案**（`status`）：留空时各版式显示自己的默认文案——横条 / 卡片留空，DSH 白卡显示事件的默认状态（如「等待你的确认」）。填了就统一用它。
- **应用名**（`eyebrow`）：卡片版式用作标题上方的小字，DSH 白卡用作左上角应用名（默认 `DeepSeek Harness`）。
- **整体缩放**：DPI 系数 × 缩放值，卡片、字号、间距、圆角一起等比缩放。
- **颜色对比度**：高级区会算正文与底色的 WCAG 对比度；低于 4.5:1 时提示，并可一键把文字改成深色或白色。
- **只在某些版式生效的控件会禁用并说明**：色条宽度 / 进度条 / 图标只用于横条；水平、垂直内边距在 DSH 白卡里不生效。

### 版式差异

| | 横条 | 卡片 | DSH 白卡 |
|---|---|---|---|
| 高度 | 最紧凑 | 随正文行数自适应 | 按公式计算，随正文行数变化 |
| 图标 | 可选圆点 | 图标板 | 鲸鱼（固定） |
| 色条 / 进度条 | 支持 | 不支持 | 强制隐藏 |
| 关闭按钮 | 无 | 无 | 右上角 × |
| 正文行数 | 最多 3 行 | 最多 3 行 | 最多 3 行 |

## 数据与日志

从 BUILD 20 起，配置和历史不再写在插件目录，而是放在：

```
%USERPROFILE%\.dsh\desktop-notify\
  settings.json      当前设置
  history.json       最近 50 条通知
  notify.log         插件运行日志（JSON 行）
  notify-click.log   渲染 / 点击日志
```

- 可用环境变量 `DSH_NOTIFY_DATA_DIR` 覆盖数据目录，`DSH_HOME` 覆盖 `.dsh` 根目录。
- 第一次加载时，如果数据目录没有 `settings.json`，会读取插件目录里旧的 `settings.json` 并迁移过来；旧文件保留不动。
- 插件的五个事件开关也接受宿主配置里的同名旧字段。
- 这些文件都在 `.gitignore` 里，不会进仓库或 npm 包。日志可能包含会话标题等本机信息，分享前先看一眼。

## 资源占用

- 空闲时：DSH 进程里的一小段 JS，无轮询、无网络请求。
- 第一张卡片出现时启动**一个常驻的 `powershell.exe` 渲染宿主**，之后所有卡片都复用它，不再每弹一次起一个进程。宿主随插件卸载 / DSH 退出而结束；连续启动失败时会退回到「每次一张短命进程」的模式。
- 设置页只在打开时渲染。

## 常见问题

**装完设置里没有「桌面通知」？**
刷新一次 DSH 页面；客户端模块需要重新加载。插件更新后也一样。

**测试有卡片，但真实通知样式没变？**
「测试通知」用页面上的当前值；真实通知用已保存的值。改完点「保存」。

**没有任何卡片？**
先看 `%USERPROFILE%\.dsh\desktop-notify\notify.log` 和 `notify-click.log`。常见原因：事件开关关了、免打扰时段、DSH 正在前台、全屏 / 勿扰 / 专注助手、系统通知被关闭。

**提权时没有卡片？**
插件监听会话事件 `approval/asked`，正常覆盖权限提升与工具授权；会话权限策略为 `never` 时不会出现确认提示，也就没有卡片。

**更新插件时连续两次提权？**
一次更新包含 `remove_bundle` + `install_bundle` 两步，两次都可能弹卡片。

**DSH 白卡底部为什么不显示倒计时？**
真实通知里，状态行始终有内容：你填了「状态行文案」就用你的，没填就用当前事件的默认文案（如「等待你的确认」）。「N 秒后收起 · 悬停可保留」只在状态行为空时出现，而插件不会传空，所以只有直接调用 `notify.ps1` 或预览无状态卡片时才能看到。

## 卸载

DSH 设置 → 插件 → 桌面通知 → 关闭/移除；或：

```powershell
dsh plugin --profile desktop rm dsh-desktop-notify-win
```

数据目录不会自动删除；要彻底清理，手动删掉 `%USERPROFILE%\.dsh\desktop-notify`。

## 已知限制

- 仅 Windows（依赖 WinForms / PowerShell）。
- 虚拟桌面切换用的是未公开 COM，Windows 大版本更新后可能失效；失效时退化为只聚焦。
- 多显示器跟随已按代码和单屏日志验证，真·双屏还需实机测试。
- 专注助手 / 全屏独占可能吞掉卡片，这是系统行为；插件在弹之前会先查一次 Windows 通知状态，能挡掉一部分。
- 「最多同屏」是直接替换最早一张，没有等待队列。
- 常驻宿主只支持一个 DSH 进程；多个 DSH 同时运行会各起一个宿主。

## 开发

- `index.js`：host 插件入口，事件监听、HTTP API、设置持久化、审批 watcher。
- `lib/schema.js`：默认值、限制、预设、事件与语义色、`sanitize()`。
- `lib/service.js`：通知编排（compose / 抑制 / 合并 / 历史 / 预览 / 重播）。
- `lib/renderer-host.js`：常驻 `notify.ps1 -Serve` 宿主的管理与一次性回退。
- `lib/config.js` / `lib/history.js` / `lib/log.js` / `lib/paths.js`：设置、历史、日志、路径。
- `notify.ps1`：WinForms 分层窗口自绘卡片、宿主协议与点击行为。
- `client.js`：设置页（六段 + 实时预览）。
- 详细交接、几何参数与踩坑记录见 [HANDOFF.md](./HANDOFF.md)。

```powershell
npm run check   # node --check：index / client / lib 下 7 个模块
```

单帧渲染调试（不弹窗）：

```powershell
powershell -File notify.ps1 -Snapshot .\snap.png
```

## 本地改造记录

基于上游 [0.4.0](https://github.com/xiaotie3088/dsh-desktop-notify-win)，BUILD 20 的主要改动：

- **拆分模块**：原来的单文件 host 拆成 `index.js` + `lib/`（schema / service / config / history / log / paths / renderer-host），渲染与调度分离。
- **常驻渲染宿主**：`notify.ps1` 新增 `-Serve` 模式，通过 stdin/stdout 的 JSON 行协议常驻，支持 `show` / `clear` / `quit` / `ping`，卡片消失、点击都会回报事件；启动失败自动回退到一次性弹窗。
- **通知调度**：五类事件开关、免打扰时段、前台 / 全屏 / 专注助手抑制、1500ms 同 key 合并、最多同屏、历史记录与抑制原因、预览与重播。
- **设置页重写**：六段式布局 + 固定实时预览 + 数据目录 / 导入导出 / 恢复默认 + WCAG 对比度提示。
- **三版式与八预设**：保留上游的横条、卡片，新增逐像素复刻的 DSH 白卡；预设从 4 套扩到 8 套。
- **自绘渲染**：分层窗口 + `UpdateLayeredWindow` 手绘，圆角、同心层投影、渐变强调条、顶部高光、淡入淡出；高度随正文行数自适应；按显示器 DPI × 整体缩放绘制。
- **DSH 白卡**：图标板 + 手绘鲸鱼、`Segoe UI Semibold` 应用名、字号按 `titleSize` / `bodySize` 固定倍率派生（1.60 / 1.385）、正文行距 1.69、双层差分描边（上左 2px、下右 1px）、彩色状态点 + 「点击切回 ›」、右上 × 独立热区；配色由底色与文字色混合派生，浅色底补一点冷色。
- **调试**：`notify.ps1 -Snapshot <path>` 直接把静态帧写成 PNG。
